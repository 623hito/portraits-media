# PORTRAITS — 人物紹介メディア（学習用）

100人の人物を紹介するメディアのひな形です。HTML・CSS・JavaScript だけで動き、ビルドは不要です。
いま入っている人物・文章はすべて架空、写真はダミー（picsum.photos）です。

## ページ

| ファイル | 中身 |
|---|---|
| `index.html` | トップ。背景の写真モザイク、特集インタビュー5人、流れる人物カード、人物の格子 |
| `people.html` | 人物一覧。職種で絞り込み、名前で検索 |
| `person.html?id=番号` | 1人ぶんの紹介ページ（全員同じ型） |
| `interview.html?id=1〜5` | 特集インタビューの記事（5人とも同じ型） |

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `data.js` | **中身はすべてここ**。メディア名、特集インタビュー、紹介する人たち |
| `common.js` | 全ページ共通のヘッダー・フッター、人物カード、ふわっと出す動き |
| `script.js` | トップページの動き（モザイク、流れる列、モーダル） |
| `style.css` | 見た目。切り替え幅は 860px（タブレット寄り）と 743px（スマホ） |

## 人を足す・直す

`data.js` の `PEOPLE_REAL` に、1人ぶんを足します。足した人が先頭に並び、足りないぶんは架空の人で96人まで埋まります。

```js
const PEOPLE_REAL = [
  { en: "TARO YAMADA", jp: "山田 太郎", role: "デザイナー",
    photo: "images/yamada.jpg",          // 写真は images フォルダに置く（縦長 3:4 がきれい）
    intro: "紹介文を2〜3行で。",
    qa: [["いまの仕事は？", "答え"], ["大切にしていることは？", "答え"]],
    keywords: ["ロゴ", "本の装丁"] },
];
```

- `role`（職種）は自由に書けます。一覧ページの絞り込みボタンは、入っている職種から自動で作られます。
- 特集インタビューは `INTERVIEWS` を直します。`qa` はいくつでも足せます。
- メディア名とひとことは `SITE` を直します。

## 手元で見る

```bash
python3 -m http.server 4820
```

ブラウザで http://localhost:4820/ を開きます。

## 使っているもの

- [Splide](https://splidejs.com/) 4.1.4 と自動スクロール拡張（流れる人物カード）
- Google Fonts：Bodoni Moda、Noto Sans JP
